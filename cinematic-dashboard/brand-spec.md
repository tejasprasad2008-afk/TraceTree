# TraceTree Unified Command Brand Spec

## Visual Identity
**Theme**: Baroque-Renaissance meets Old-Money Opera House.
**Aesthetic**: Neoclassical collage, fine-art etching details, architectural grids.

## Palette (OKLch & Hex)
- **Canvas Base**: `oklch(96.5% 0.01 85)` / `#F5F2EB` (Warm Parchment/Cream)
- **Typography**: `oklch(22% 0.01 70)` / `#1D1B18` (Rich Coal/Charcoal)
- **Primary Accent**: `oklch(58% 0.16 35)` / `#D45B3F` (Terracotta / Burnt Orange)
- **Secondary Accent**: `oklch(82% 0.12 30)` / `#FFC3B2` (Summer Peach-Pink)
- **Highlights**: `oklch(72% 0.12 85)` / `#C5A059` (Antique Gold Leaf)
- **Borders**: `oklch(88% 0.02 85)` / `#D8D3C5` (Antique Sand)

## Typography
- **Headings**: Cormorant Garamond (Editorial Serif, Italic accents)
- **Body**: Inter / Outfit (Premium Sans-Serif)
- **Data**: JetBrains Mono (Monospace Ledger)

## Layout Rules
- Asymmetric newspaper masthead.
- Fine hairline borders (0.5px - 1px).
- "Plate" numbering for visual elements (e.g., FIG. 01).
- Large serif display type with tight leading.
